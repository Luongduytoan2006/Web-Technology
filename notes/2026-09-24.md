## 0. Cài XAMPP ở đâu và bắt đầu như thế nào?

### 0.1. Nên cài ở ổ C hay ổ D?

XAMPP chạy được ở cả `C:\xampp` và `D:\xampp`; ổ đĩa không làm thay đổi cách PHP hay Apache hoạt động. Nên chọn đường dẫn ngắn, không dấu và không có khoảng trắng.

**Với máy hiện tại, nên dùng `D:\xampp`** vì:

- Ổ D còn nhiều dung lượng trống hơn ổ C.
- Thư mục học tập và dự án cũng đang nằm trên ổ D, dễ quản lý và sao lưu.
- Tránh làm ổ hệ điều hành C đầy thêm.
- `D:\xampp` vẫn là đường dẫn ngắn, không dấu, không khoảng trắng nên Apache/PHP đọc ổn định.

`C:\xampp` cũng không sai và thường xuất hiện trong tài liệu hướng dẫn. Nếu học trên máy phòng thực hành, cần kiểm tra XAMPP thực tế được cài ở ổ nào rồi thay đường dẫn tương ứng.

Không nên cài vào các đường dẫn như:

```text
D:\Program Files\xampp
D:\Công nghệ Web\xampp
```

vì khoảng trắng và ký tự tiếng Việt có thể gây lỗi với một số script hoặc cấu hình cũ.

### 0.2. Các bước cài đặt cơ bản

1. Chạy bộ cài XAMPP 64-bit.
2. Chọn tối thiểu: **Apache, MySQL, PHP và phpMyAdmin**.
3. Chọn thư mục cài đặt `D:\xampp`.
4. Sau khi cài, mở `D:\xampp\xampp-control.exe` bằng **Run as administrator**.
5. Nhấn **Start Apache** để chạy web PHP.
6. Nhấn **Start MySQL** khi bài học cần cơ sở dữ liệu.
7. Khi mới học, chưa cần đánh dấu cột **Service**; nên Start/Stop thủ công để quan sát trạng thái và cổng.

> [!NOTE]
> Mục **MySQL** trong XAMPP 8.2 thực tế là MariaDB, nhưng giao thức, câu lệnh SQL và cách kết nối PHP/MySQL cơ bản gần như tương thích. Bản cài hiện tại có Apache 2.4.58, PHP 8.2.12 và MariaDB 10.4.32. Máy hiện đang dùng HTTP port `8036`; phpMyAdmin chưa được cài nên nút **Admin** của MySQL trả `403 Forbidden`.

### 0.3. Cổng đang dùng

```text
HTTP:        http://localhost:8036/  -> Apache
HTTPS:       https://localhost/      -> Apache SSL, port 443
Database:    127.0.0.1:3306          -> MariaDB/MySQL của XAMPP
```

Trong `D:\xampp\apache\conf\httpd.conf`, hai dòng HTTP phải thống nhất:

```apache
Listen 8036
ServerName localhost:8036
```

Một cổng Apache phục vụ được nhiều dự án. Không cần cấp một port riêng cho từng folder:

```text
D:\xampp\htdocs\project_a -> http://localhost:8036/project_a/
D:\xampp\htdocs\project_b -> http://localhost:8036/project_b/
```


### 0.6. Apache và PHP đọc code theo thứ tự nào?

Khi mở:

```text
http://localhost:8036/test_09_24/
```

luồng xử lý là:

```text
1. Trình duyệt kết nối localhost qua port 8036.
2. Apache nhận request vì đang Listen 8036.
3. Apache lấy DocumentRoot D:/xampp/htdocs.
4. URL /test_09_24/ được ánh xạ tới D:/xampp/htdocs/test_09_24/.
5. Vì URL không ghi tên file, Apache tìm DirectoryIndex, thường là index.php.
6. Apache thấy đuôi .php nên chuyển file cho PHP interpreter.
7. PHP đọc index.php từ trên xuống dưới:
   - HTML bên ngoài <?php ... ?> được đưa thẳng vào response.
   - Code trong <?php ... ?> được thực thi trên server.
   - Gặp include/require thì PHP đọc file được nhúng ngay tại vị trí đó.
   - Nếu có truy vấn database, PHP kết nối tới port 3306 và chờ kết quả.
8. PHP tạo kết quả cuối cùng, thường là HTML.
9. Apache gửi HTTP response về trình duyệt.
10. Trình duyệt đọc HTML, rồi tải CSS, JavaScript và hình ảnh nếu trang tham chiếu tới chúng.
```

Điểm cần nhớ:

- File `.html` chủ yếu là nội dung tĩnh; Apache gửi nguyên nội dung cho trình duyệt.
- File `.php` có thể chứa cả HTML và PHP; code PHP chạy ở server, trình duyệt chỉ nhận kết quả.
- PHP chạy qua Apache dùng port của Apache (`8036`), không tự mở một port riêng.
- Database là tiến trình khác và dùng port `3306`.
- Khi đọc một dự án lạ, bắt đầu từ URL đang mở → `index.php` → các lệnh `include`/`require` → file xử lý → câu SQL/database → HTML trả về.

## I. Review sơ bộ: XAMPP là gì và gồm những gì?

### 1. Khái niệm cốt lõi
* **XAMPP** là gói giải pháp máy chủ cục bộ (**Local Web Server**) tất cả trong một (All-in-One), giúp biến máy tính cá nhân thành một máy chủ web mà không cần cấu hình phức tạp từng phần mềm riêng lẻ.
* **Ý nghĩa tên gọi XAMPP:**
  * **X** (*Cross-Platform*): Đa nền tảng (chạy được trên Windows, Linux, macOS).
  * **A** (*Apache*): Web Server tiếp nhận và trả lời các HTTP Request từ trình duyệt.
  * **M** (*MySQL / MariaDB*): Hệ quản trị cơ sở dữ liệu quan hệ lưu trữ data.
  * **P** (*PHP*): Ngôn ngữ kịch bản phía máy chủ xử lý logic và truy vấn dữ liệu.
  * **P** (*Perl*): Ngôn ngữ kịch bản khác (ít dùng trong môn học này).

## II. Nội dung học từ slide 12: PHP cơ bản

Nguồn học: `Tài Liệu Học Phần/CongNgheWeb_Session4.pdf`, bắt đầu từ slide 12.

### 1. Tám kiểu dữ liệu chính trong PHP

| Nhóm | Kiểu | Ý nghĩa ngắn |
| :--- | :--- | :--- |
| Vô hướng | `boolean` | Chỉ nhận `true` hoặc `false`. |
| Vô hướng | `integer` | Số nguyên, ví dụ `10`, `-3`, `0`. |
| Vô hướng | `float` / `double` | Số thực, ví dụ `1.25`, `1.2e3`. |
| Vô hướng | `string` | Chuỗi ký tự đặt trong nháy đơn hoặc nháy kép. |
| Tổ hợp | `array` | Một tập hợp nhiều giá trị, có thể dùng chỉ số hoặc cặp key-value. |
| Tổ hợp | `object` | Đối tượng được tạo từ class. |
| Đặc biệt | `resource` | Tham chiếu tới tài nguyên bên ngoài như file hoặc kết nối. |
| Đặc biệt | `NULL` | Biến không có giá trị. |

Ví dụ:

```php
<?php
$isStudent = true;             // boolean
$age = 20;                     // integer
$score = 8.5;                  // float
$name = "Duy Toàn";           // string
$subjects = ["PHP", "HTML"]; // array dạng danh sách
$student = null;               // NULL
?>
```

Có thể kiểm tra kiểu và giá trị bằng:

```php
var_dump($score);      // float(8.5)
var_dump($subjects);   // hiển thị cấu trúc array
```

#### String: nháy đơn và nháy kép

```php
$name = "Toàn";

echo 'Xin chào $name'; // in nguyên văn: Xin chào $name
echo "Xin chào $name"; // thay biến: Xin chào Toàn
```

- Nháy đơn `'...'`: nội suy biến không diễn ra.
- Nháy kép `"..."`: giá trị biến có thể được chèn vào chuỗi.
- Dùng `\` để escape ký tự đặc biệt, ví dụ `"Dấu \"nháy kép\""`.

### 2. Array: mảng chỉ số và mảng kết hợp

Mảng chỉ số:

```php
$names = ["An", "Bình", "Toàn"];

echo $names[0]; // An
echo $names[2]; // Toàn
```

Mảng kết hợp dùng cặp `key => value`:

```php
$student = [
    "name" => "Duy Toàn",
    "age" => 20,
    "major" => "CNTT"
];

echo $student["name"]; // Duy Toàn
```

Slide dùng `array(...)`; PHP hiện đại thường viết ngắn bằng `[...]`. Hai cách đều hợp lệ:

```php
$a = array(1, 2, 3);
$b = [1, 2, 3];
```

### 3. Biến và biểu thức

- Tên biến bắt đầu bằng `$`, ví dụ `$name`.
- PHP phân biệt hoa thường: `$name` và `$Name` là hai biến khác nhau.
- Một biểu thức tạo ra một giá trị, ví dụ `$total = $a + $b`.
- Nên đặt tên biến bằng chữ cái hoặc `_`, sau đó có thể chứa chữ số.

```php
$a = 5;
$b = 3;
$total = $a + $b; // biểu thức $a + $b tạo ra giá trị 8
```

### 4. Các nhóm toán tử cơ bản

#### 4.1. Toán tử số học

```php
$a + $b; // cộng
$a - $b; // trừ
$a * $b; // nhân
$a / $b; // chia
$a % $b; // chia lấy dư
```

#### 4.2. Toán tử gán và cập nhật

```php
$a = 10;
$a += 2; // tương đương $a = $a + 2
$a -= 2; // tương đương $a = $a - 2
$a *= 2; // tương đương $a = $a * 2
$a /= 2; // tương đương $a = $a / 2
$a %= 3; // tương đương $a = $a % 3
$a++;    // tăng 1
$a--;    // giảm 1
```

#### 4.3. Nối chuỗi bằng dấu chấm `.`

```php
$firstName = "Duy";
$lastName = "Toàn";
$fullName = $firstName . " " . $lastName;

echo $fullName; // Duy Toàn
```

Không dùng dấu `+` để nối chuỗi như một số ngôn ngữ khác.

#### 4.4. Toán tử so sánh

```php
$a == $b;  // bằng nhau về giá trị
$a === $b; // bằng cả giá trị và kiểu dữ liệu
$a != $b;  // khác nhau
$a < $b;
$a <= $b;
$a > $b;
$a >= $b;
```

Ví dụ quan trọng:

```php
var_dump(5 == "5");  // true: PHP chuyển kiểu khi so sánh
var_dump(5 === "5"); // false: integer khác string
```

Khi có thể, nên ưu tiên `===` và `!==` để tránh lỗi do PHP tự chuyển kiểu.

#### 4.5. Toán tử logic

```php
!$condition;                 // NOT
$age >= 18 && $hasCard;      // AND
$isAdmin || $isTeacher;      // OR
```

PHP cũng có `and` và `or`, nhưng độ ưu tiên khác `&&` và `||`; khi mới học nên dùng `&&`, `||` và thêm ngoặc khi biểu thức dài.

#### 4.6. Toán tử ba ngôi

```php
$result = $score >= 5 ? "Đạt" : "Chưa đạt";
```

Ý nghĩa:

```text
điều_kiện ? giá_trị_khi_đúng : giá_trị_khi_sai
```

Slide có giới thiệu toán tử `@` để ẩn lỗi. Không nên lạm dụng vì nó che mất nguyên nhân; khi học và debug nên để lỗi hiển thị rồi sửa đúng lỗi.

### 5. Ba mẫu lặp với `for` và `foreach`

Đây là ba mẫu bạn vừa nghe trên lớp. Chính xác là **một cấu trúc `for` và hai dạng cú pháp của `foreach`**.

#### 5.1. `for` kiểu C

Phù hợp khi biết số lần lặp hoặc cần dùng chỉ số `$i`:

```php
$names = ["An", "Bình", "Toàn"];
$count = count($names);

for ($i = 0; $i < $count; $i++) {
    echo $names[$i] . "<br>";
}
```

Thứ tự chạy:

```text
$i = 0 -> kiểm tra $i < $count -> chạy thân vòng lặp -> $i++ -> kiểm tra lại
```

#### 5.2. `foreach` chỉ lấy value

Phù hợp khi chỉ cần từng giá trị trong array:

```php
$names = ["An", "Bình", "Toàn"];

foreach ($names as $name) {
    echo $name . "<br>";
}
```

Mỗi vòng lặp, `$name` lần lượt nhận `"An"`, `"Bình"`, rồi `"Toàn"`.

#### 5.3. `foreach` lấy cả key và value

Phù hợp với mảng kết hợp hoặc khi cần biết chỉ số:

```php
$student = [
    "name" => "Duy Toàn",
    "age" => 20,
    "major" => "CNTT"
];

foreach ($student as $key => $value) {
    echo $key . ": " . $value . "<br>";
}
```

Kết quả:

```text
name: Duy Toàn
age: 20
major: CNTT
```

Ghi nhớ nhanh:

```php
for ($i = 0; $i < $n; $i++) { ... }
foreach ($array as $value) { ... }
foreach ($array as $key => $value) { ... }
```

## III. Bí kíp "Phòng thủ" khi đi thi thực hành & Sử dụng XAMPP

### 1. Quy trình chuẩn để đóng gói dự án an toàn (ZIP)

> [!TIP]
> Trước khi nộp bài hoặc kết thúc buổi làm việc, luôn thực hiện đủ 3 bước:

1. **Xuất Cơ sở dữ liệu (Export Database):**
   * Sau khi phpMyAdmin đã được cài, mở `http://localhost:8036/phpmyadmin/`.
   * Chọn Database của dự án ở cột bên trái.
   * Chọn tab **Export (Xuất)** $\rightarrow$ Chọn phương thức **Quick (Nhanh)** $\rightarrow$ Nhấn **Export** để tải về file `ten_database.sql`.
   * Di chuyển file `.sql` này bỏ vào ngay trong thư mục code dự án (ví dụ tạo thư mục `database/ten_database.sql`).

2. **Nén thư mục dự án:**
   * Vào `D:\xampp\htdocs\`.
   * Click chuột phải vào thư mục bài làm `ten_du_an` $\rightarrow$ Chọn **Compress to ZIP file** (hoặc dùng WinRAR/7-Zip).
   * Lưu file zip ở nơi an toàn (USB, Google Drive, Mail cá nhân...).

3. **Khi vào máy thi:**
   * Khởi động XAMPP Control Panel $\rightarrow$ Start Apache & MySQL.
   * Giải nén file `.zip` vào thư mục `htdocs` thực tế trên máy thi.
   * Mở URL phpMyAdmin theo port Apache của máy $\rightarrow$ tạo CSDL đúng tên $\rightarrow$ chọn **Import** $\rightarrow$ chọn file `.sql`.
   * Mở URL dự án theo đúng port Apache, ví dụ `http://localhost:8036/ten_du_an/`.

### 2. Các lỗi kinh điển tại phòng máy thi và cách xử lý nhanh

#### 🔴 Lỗi 1: Apache không Start được (Báo đỏ hoặc đụng cổng 80 / 443)
* **Nguyên nhân:** Máy thi có cài Skype, VMware, World Wide Web Publishing Service (IIS), hoặc phần mềm khác đang chiếm cổng 80.
* **Cách xử lý:**
  1. Trên XAMPP Control Panel, tại hàng **Apache**, bấm nút **Config** $\rightarrow$ chọn `httpd.conf`.
  2. Bấm `Ctrl + F` tìm dòng `Listen 80` $\rightarrow$ đổi thành `Listen 8080`.
  3. Tìm tiếp `ServerName localhost:80` $\rightarrow$ đổi thành `ServerName localhost:8080`.
  4. Lưu file và Start lại Apache.
  5. *Lưu ý:* Khi gõ trên trình duyệt phải thêm cổng: `http://localhost:8080/ten_du_an/`.

#### 🔴 Lỗi 2: MySQL tắt đột ngột ("MySQL shutdown unexpectedly")
* **Nguyên nhân:** Máy bị sập nguồn hoặc tắt XAMPP không đúng cách làm hỏng file cache dữ liệu.
* **Cách cấp cứu nhanh (không làm mất dữ liệu):**
  1. Vào thư mục `D:\xampp\mysql\` (hoặc thư mục XAMPP thực tế trên máy).
  2. Đổi tên thư mục `data` thành `data_old`.
  3. Copy thư mục `backup` và dán ra, đổi tên bản copy đó thành `data`.
  4. Mở thư mục `data_old`, copy toàn bộ các thư mục chứa cơ sở dữ liệu của bạn và file `ibdata1` dán đè sang thư mục `data` mới.
  5. Bấm Start lại MySQL trong XAMPP.

#### 🔴 Lỗi 3: Kết nối CSDL bị từ chối (`Access denied for user 'root'@'localhost'`)
* **Nguyên nhân:** Code ở nhà đặt mật khẩu MySQL khác với máy thi (mặc định XAMPP để user là `root` và password là chuỗi rỗng `""`).
* **Chuẩn code kết nối an toàn cho phòng thi:**
  ```php
  <?php
  $servername = "localhost";
  $username = "root";
  $password = ""; // Mặc định trên XAMPP để trống
  $dbname = "ten_database_cua_ban";

  $conn = new mysqli($servername, $username, $password, $dbname);

  if ($conn->connect_error) {
      die("Kết nối thất bại: " . $conn->connect_error);
  }
  // Thiết lập bảng mã UTF-8 chống lỗi tiếng Việt
  $conn->set_charset("utf8mb4");
  ?>
  ```
