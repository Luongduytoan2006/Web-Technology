# 1. Mô hình Client - Server (4 mô hình xử lý phổ biến)

| STT | Mô hình | Phía Client (FE) | Phía Server (BE) | Ghi chú |
| :---: | :--- | :--- | :--- | :--- |
| **1** | Trình bày từ xa | Presentation | Application logic, Data management | |
| **2** | Xử lý phân tán | Presentation, Application logic | Application logic, Data management | |
| **3** | Quản lý dữ liệu từ xa | Presentation, Application logic | Data management | Toàn bộ logic viết ở Client $\rightarrow$ bảo mật phải cực kỳ kỹ |
| **4** | Quản lý dữ liệu phân tán | Presentation, Application logic, Data management | Data management | Khó nhất: đa thiết bị, nhiều truy cập đồng thời $\rightarrow$ phân tán hệ thống (Distributed system), cần lập trình các bản sao |


Mô hình 1 (Trình bày từ xa)
- Đứng từ xa nhập thông tin, đưa xuống server xử lý và trả về.
- Vì server chứa hết -> Bảo mật cao, tốn tài nguyên server nếu nhiều request cùng lúc

Mô hình 2 (Xử lý phân tán - Phân tán chức năng xử lý nhưng dữ liệu tập trung)
- FE xử lý một phần, BE xử lý một phần

Mô hình 3 (Quản lý dữ liệu từ xa)
- Design Pattern thứ 24 viết về cái này
