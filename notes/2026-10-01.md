## I. Hàm do người dùng định nghĩa (Functions)

### 1. Định nghĩa và Cú pháp
Hàm giúp đóng gói các đoạn mã được dùng nhiều lần, dễ bảo trì và tái sử dụng.

```php
function tenHam($thamSo1, $thamSo2 = "gia_tri_mac_dinh") {
    // Thân hàm thực hiện công việc
    return $ketQua; // Trả về kết quả nếu có
}
```

- **Tham số mặc định:** Đặt ở cuối danh sách tham số. Nếu khi gọi hàm không truyền giá trị, PHP sẽ tự lấy giá trị mặc định.
- **Giá trị trả về (`return`):** Trả về giá trị của biểu thức, kết thúc việc thực thi hàm ngay tại vị trí đó.

### 2. Phạm vi biến (Variable Scope)
- **Biến cục bộ:** Khai báo bên trong hàm, chỉ có hiệu lực trong phạm vi hàm đó.
- **Biến toàn cục:** Khai báo bên ngoài hàm. Để sử dụng biến toàn cục bên trong thân hàm, dùng từ khóa `global` hoặc mảng siêu toàn cục `$GLOBALS`:

```php
$x = 10;

function kiemTra() {
    global $x; // Gọi biến toàn cục $x vào thân hàm
    echo $x;
    // Hoặc dùng: echo $GLOBALS['x'];
}
```

## II. Tái sử dụng mã chương trình (`include` và `require`)

PHP cung cấp 4 lệnh để nhúng nội dung từ file khác vào file hiện tại:

| Lệnh | Ý nghĩa & Hành vi khi file không tồn tại |
| :--- | :--- |
| `include("file.php")` | Báo **Warning** (cảnh báo nhẹ), chương trình **vẫn tiếp tục chạy** tiếp các đoạn code phía dưới. |
| `require("file.php")` | Báo **Fatal Error** (lỗi nghiêm trọng), chương trình **dừng thực thi ngay lập tức**. |
| `include_once("file.php")` | Giống `include` nhưng chỉ nhúng **đúng 1 lần duy nhất**, chống định nghĩa lại hàm/lớp trùng lặp. |
| `require_once("file.php")` | Giống `require` nhưng chỉ nhúng **đúng 1 lần duy nhất**. Thường dùng để nhúng file cấu hình kết nối DB (`connect.php`). |

## III. Xử lý Form và Nhận dữ liệu

Khi người dùng gửi form HTML lên máy chủ, PHP nhận dữ liệu qua các mảng siêu toàn cục:

- `$_GET`: Nhận dữ liệu gửi qua URL (method `GET`). Nhìn thấy được tham số trên thanh địa chỉ, thích hợp cho tìm kiếm, phân trang.
- `$_POST`: Nhận dữ liệu gửi ngầm trong HTTP Body (method `POST`). Kín đáo hơn, kích thước dữ liệu lớn hơn, bắt buộc dùng cho mật khẩu, thêm mới dữ liệu.
- `$_REQUEST`: Mảng tổng hợp nhận cả `$_GET`, `$_POST` và `$_COOKIE`.

```php
<?php
// Kiểm tra khi submit form
if (isset($_POST['btnGui'])) {
    $ten = $_POST['txtHoTen'];
    $matkhau = $_POST['txtMatKhau'];
    echo "Xin chào: " . $ten;
}
?>
```

- **Chuyển hướng trang:** Dùng hàm `header("Location: trang_khac.php");` (chú ý không để có bất kỳ thẻ HTML hoặc lệnh `echo` nào xuất hiện trước hàm này).

## IV. Cơ bản về Hệ quản trị CSDL MySQL & Khởi tạo kết nối

### 1. Luồng truy xuất CSDL bằng PHP
1. **Thiết lập kết nối** đến MySQL Server.
2. **Chọn CSDL** cần làm việc.
3. **Thực thi câu lệnh SQL** (SELECT, INSERT, UPDATE, DELETE).
4. **Nhận kết quả** và xử lý hiển thị.
5. **Đóng kết nối** CSDL.

### 2. Các hàm kết nối theo slide (Slide 54 - 58)

```php
<?php
// 1. Kết nối đến MySQL Server
$link = mysql_connect("localhost", "root", "") or die("Khong the ket noi den CSDL MySQL");

// 2. Chọn CSDL
mysql_select_db("DULIEU", $link);

// 3. Thực thi truy vấn thử nghiệm
$sql = "SELECT * FROM phongban";
$rs = mysql_query($sql, $link);

// 4. Đóng kết nối
mysql_close($link);
?>
```

> [!NOTE]
> Trên môi trường PHP 8.2 (XAMPP mới), nhóm hàm `mysql_*` được thay thế bằng `mysqli_*`:
> ```php
> $link = mysqli_connect("localhost", "root", "", "DULIEU") or die("Lỗi kết nối");
> $rs = mysqli_query($link, "SELECT * FROM phongban");
> mysqli_close($link);
> ```
