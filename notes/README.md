# Notes môn Công nghệ Web

Quy ước ghi note:

- Mỗi buổi học tạo một file trong thư mục `notes`.
- Tên file theo dạng `năm-tháng-ngày.md`, ví dụ `2026-08-13.md`.
- Nội dung ưu tiên: ý chính trên lớp, giải thích dễ hiểu, ví dụ gần với bài học, và phần ghi nhớ nhanh.
- Nếu có nội dung gốc từ lớp hoặc lời nhắc của thầy/cô, giữ lại ở cuối file để đối chiếu.
