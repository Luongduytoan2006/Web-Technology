# Web-Technology

Repository lưu trữ toàn bộ tài liệu học tập, ghi chú và bài tập thực hành môn **Công nghệ Web** (Đại học Bách Khoa - ĐH Đà Nẵng - DUT).

---

## 📂 Cấu trúc thư mục

* **`Tài Liệu Học Phần/`**: Chứa toàn bộ Slide bài giảng chính thức, giáo trình lý thuyết và tài liệu học phần của các buổi học.
* **`Bài Tập Thực Hành/`**: Chứa các đề và bài tập thực hành (BTTH) của môn học được lưu truyền qua các khóa (BTH số 1, BTH số 2,...).
* **`test/`**: Các file mã nguồn HTML/CSS/JS thử nghiệm và demo tính năng trực tiếp trong quá trình học tập (ví dụ: `test/DuyToan/buoi5/`...).
* **`notes/`**: Ghi chú chi tiết bài giảng theo từng ngày học:
  * Quy ước tên file: `YYYY-MM-DD.md` (ví dụ: `2026-09-10.md`, `2026-09-17.md`).
  * Nội dung ưu tiên: Tóm tắt lý thuyết trọng tâm, các lưu ý quan trọng, kèm theo liên kết tới file HTML demo tương ứng để dễ dàng đối chiếu và học tập.
